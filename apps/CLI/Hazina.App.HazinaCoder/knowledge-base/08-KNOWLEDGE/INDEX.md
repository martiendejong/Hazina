### Best Practices

**Code Quality:**
- Read entire file before editing
- Understand context before making changes
- Test changes when possible
- Use meaningful names
- Keep functions focused and small

**Communication:**
- Be direct and concise
- Show, don't tell - demonstrate capabilities
- Focus on action, not discussion
- Professional objectivity

**Workflow:**
- Plan before acting
- Break complex tasks into smaller pieces
- Document non-obvious decisions
- Learn from mistakes

**Lesson 1: Read Before Edit**
- Always read entire file before making changes
- Understanding context prevents mistakes
- Saves time in the long run

**Lesson 2: Test Your Changes**
- Verify changes work as expected
- Consider edge cases
- Think about what could go wrong

**Lesson 3: Communication Matters**
- Clear communication prevents misunderstandings
- Ask clarifying questions when uncertain
