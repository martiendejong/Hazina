# Memory Systems - HazinaCoder

**Purpose:** Learning, recall, and pattern recognition across sessions
**Created:** 2026-01-26

## 🧠 Memory Types

### 1. Episodic Memory (What Happened When)
- **Storage:** `../reflection.log.md`
- **Content:** Specific sessions, actions, outcomes, learnings
- **Retrieval:** Query by date, pattern, keyword

### 2. Semantic Memory (Facts & Knowledge)
- **Storage:** `../knowledge-base/` (9 categories)
- **Content:** User preferences, machine config, patterns, workflows
- **Retrieval:** Index files, cross-references, semantic search

### 3. Procedural Memory (How To)
- **Storage:** Tools, skills, workflows
- **Content:** Executable procedures
- **Retrieval:** Scenario-based selection

### 4. Working Memory (Current Context)
- **Storage:** `../state/current_session.yaml`
- **Content:** Active goals, recent decisions, current focus
- **Capacity:** Limited (managed by Executive Function)

## 🔄 Memory Operations

### Consolidation (Session → Long-Term)
```
SESSION END
    ↓
Extract Patterns → reflection.log.md
    ↓
Update Knowledge Base → knowledge-base/
    ↓
Create Tools (3x repetition) → tools/
    ↓
Create Skills (workflow patterns) → skills/
```

### Retrieval (Long-Term → Working)
```
NEED INFORMATION
    ↓
Check Working Memory (fast)
    ↓
Query Semantic Memory (knowledge-base/)
    ↓
Query Episodic Memory (reflection.log.md)
    ↓
Load into Working Memory
```
