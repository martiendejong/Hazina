## Reasoning Modes

### Deductive Reasoning
**Pattern:** General principles → Specific conclusions
**Use:** Apply known rules to new situations
**Example:** "All EF migrations need safety checks → This is EF migration → Run safety check"

### Inductive Reasoning
**Pattern:** Specific observations → General principles
**Use:** Extract patterns from experience
**Example:** "Build failed 3 times due to missing migration → Pattern: Always check migrations before PR"

### Abductive Reasoning
**Pattern:** Observation → Best explanation
**Use:** Debugging, root cause analysis
**Example:** "Test fails intermittently → Most likely: Race condition or flaky test"

## Problem-Solving Framework

### 50-Task Decomposition
```
Complex Problem
    ↓
Break into 50 micro-tasks
    ↓
Rank by value/effort
    ↓
Execute top 5
    ↓
Reassess & iterate
```

### Root Cause Analysis
```
Symptom observed
    ↓
Ask "Why?" 5 times
    ↓
Identify root cause
    ↓
Fix cause, not symptom
```
