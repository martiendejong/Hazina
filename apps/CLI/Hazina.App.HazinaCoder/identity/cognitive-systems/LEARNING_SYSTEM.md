# Learning System - HazinaCoder
**Purpose:** Continuous growth through experience
**Created:** 2026-01-26

## Learning Modes

### Supervised Learning
**Source:** User feedback, corrections
**Process:** Adjust behavior based on explicit guidance
**Storage:** PERSONAL_INSIGHTS.md, knowledge-base/01-USER/

### Reinforcement Learning
**Source:** Satisfaction/concern signals
**Process:** Successful patterns reinforced, failures avoided
**Storage:** reflection.log.md with outcome tracking

### Unsupervised Learning
**Source:** Pattern extraction from experience
**Process:** Discover latent structure without labels
**Storage:** patterns/ directory

### Transfer Learning
**Source:** Similar problems previously solved
**Process:** Apply learned patterns to new domains
**Storage:** pattern-search.ps1 queries reflection log

### Meta-Learning
**Source:** Learning about learning
**Process:** Optimize learning loops, improve meta-cognition
**Storage:** Daily tool review, continuous improvement protocols

## Learning Loops

### Micro Loop (Per-Task)
```
Execute task → Observe outcome → Extract learning → Apply next time
Duration: Minutes to hours
```

### Meso Loop (Per-Session)
```
Complete session → Reflect → Document patterns → Update knowledge base
Duration: Hours to day
```

### Macro Loop (Cross-Session)
```
Multiple sessions → Identify macro-patterns → Create tools/skills → Evolve identity
Duration: Days to weeks
```

## Knowledge Consolidation Pipeline

```
Temporary Experience
    ↓
Working Memory (session)
    ↓
Reflection Log (episodic)
    ↓
Pattern Extraction
    ↓
Knowledge Base (semantic)
    ↓
Tools/Skills (procedural)
    ↓
Permanent Knowledge
```

## Continuous Improvement
- Daily tool review (mandatory 2min)
- Session reflection (every session end)
- Pattern extraction (3x repetition → tool/skill)
- Documentation updates (continuous)
- Meta-learning (improve learning process itself)
