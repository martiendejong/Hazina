# Hazina NuGet Packages Catalog

Complete catalog of all Hazina NuGet packages published to [NuGet.org](https://www.nuget.org/packages?q=Hazina).

## Installation

Install packages via .NET CLI:

```bash
dotnet add package Hazina.<PackageName>
```

Or via Package Manager Console:

```powershell
Install-Package Hazina.<PackageName>
```
