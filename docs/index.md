# Hazina Framework Documentation

Welcome to the Hazina Framework documentation. Hazina is a comprehensive .NET framework for building AI-powered applications with advanced features like RAG (Retrieval-Augmented Generation), multi-agent systems, and context engineering.

- [API Reference](api/) - Detailed API documentation

- [Configuration Guide](CONFIGURATION_GUIDE.md) - Learn how to configure Hazina

## Key Features

- **AI-Powered**: Integration with multiple LLM providers (OpenAI, Anthropic, Llama, etc.)
- **RAG & Search**: Advanced retrieval-augmented generation capabilities
- **Multi-Agent Systems**: Build complex agent orchestration workflows
- **Context Engineering**: Intelligent context compression and management
- **Storage Abstraction**: Support for multiple storage backends (PostgreSQL, SQLite, Supabase)
- **Tool Agents**: Extensible tool system for agent capabilities

## Framework Structure

Hazina is organized into several core modules:

- **Hazina.AI.Agents** - Agent orchestration and management
- **Hazina.AI.Memory** - Memory systems for agents
- **Hazina.AI.ContextEngineering** - Context compression and engineering
- **Hazina.Storage** - Storage abstraction layer
- **Hazina.Search** - Search and retrieval capabilities
- **Hazina.Tools** - Tool system for extending agent capabilities
